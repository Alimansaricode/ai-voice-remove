# 🎙️ AI Voice Remover

An AI-powered voice enhancement application designed to reduce background noise and help users achieve clearer audio.

## ✨ Features

- 🎤 Upload audio files
- 🎧 Preview audio before processing
- 🔇 Background noise reduction
- ▶️ Audio playback
- 💾 Export or download processed audio (if implemented)
- 📱 Responsive user interface

## 🛠️ Tech Stack

- **Frontend:** React.js
- **Build Tool:** Vite
- **Language:** JavaScript
- **Styling:** Tailwind CSS
- **Audio Processing:** DeepFilterNet3 integration (experimental, if configured)

## 🚀 Getting Started

### Prerequisites

- Node.js
- npm
- Visual Studio Code

### Installation

1. Clone the repository:

   ```bash
   git clone YOUR_AI_VOICE_REPOSITORY_URL
   ```

2. Open the project folder:

   ```bash
   cd YOUR_PROJECT_FOLDER
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.
